# Homelab

Documentation and supporting files for building and operating the homelab.

## Repository layout

- `docs/phases/` — implementation notes organized by project phase.
- `docs/reference/` — current-state and general reference documentation.
- `docs/services/` — documentation for deployed services.
- `configs/` — configuration examples and templates.
- `scripts/` — operational and setup scripts.
- `diagrams/` — network, system, and service diagrams.

- [Phase 0 — Platform Bring-Up & OS Deployment](docs/phases/phase-00-platform-bring-up/)
- [Phase 1 — Baseline Validation & Secure Remote Administration](docs/phases/phase-01-baseline-validation-secure-remote-administration/)
- Later phases will be added as the homelab evolves.
